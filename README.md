# POWERBI---Set-up-a-common-date-table

This project demonstrates how to create and use a common date table in Power BI to support time-based analysis. It shows how adding a centralized date table improves reporting, enables time intelligence calculations, and helps build a well-structured data model for analysis. 


*Date Dimension Table: A structured table containing dates and related attributes used for time analysis.

*DAX: A formula language in Power BI used to create calculations and data models.

*Power Query: A tool for connecting, transforming, and preparing data.

*CALENDAR Function: A DAX function that generates a continuous range of dates for building a date table.

**Why Useful:**  
Enables trend analysis, period comparisons, and time intelligence in datasets that lack a built-in date table.

**Getting Started:**  
1. Open AdventureWorks.pbix in Power BI Desktop.  
2. Create a date table using `CALENDAR` function.  
3. Add columns: Year, Month, Month Number, Day of Week, Week Number.  
4. Mark table as a date table and link to fact table.  

**Tools & Concepts:**  
- Power BI Desktop  
- DAX (CALENDAR, YEAR, MONTH, WEEKNUM, WEEKDAY)  
- Power Query  

**Outcome:**  
Learn how to structure a date table for scalable, time-based analysis in Power BI.
